# Aplicaciones de Minería de Datos 📊

🚧 **Aviso de Desarrollo:** Este repositorio está en proceso de construcción. El material, los *datasets* y las prácticas se actualizan semanalmente conforme avanza el ciclo escolar. 🚧

Repositorio oficial del curso universitario de **Aplicaciones de Minería de Datos**. Este material está diseñado específicamente para estudiantes de ingeniería de software, enfocándose en la implementación práctica del proceso KDD (*Knowledge Discovery in Databases*) mediante programación vectorizada y arquitectura de datos.

## 🎯 Objetivo del Curso
Cerrar la brecha entre la ingeniería de software tradicional y la ciencia de datos. Los estudiantes aprenderán a extraer, limpiar, transformar y preparar grandes volúmenes de datos para su posterior consumo por algoritmos de *Machine Learning*, entendiendo las implicaciones geométricas y de rendimiento detrás de cada línea de código.

## 🛠️ Stack Tecnológico
El curso se imparte utilizando un entorno de ciencia de datos moderno en Python:
* **Python 3.x**
* **Pandas & NumPy:** Manipulación de datos y álgebra lineal vectorizada.
* **Jupyter Notebooks:** Entorno de experimentación y análisis interactivo.
* **Matplotlib / Seaborn:** Visualización analítica de datos.
* **Scikit-Learn:** (Próximamente para la fase de modelado).

## 🚀 Cómo utilizar este repositorio

Para ejecutar los *notebooks* de las sesiones y las tareas localmente:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/mricardo89/data-mining.git
   cd data-mining
   ```

2. **Crea un entorno virtual (Recomendado):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # En Windows usa: venv\Scripts\activate
   ```

3. **Instala las dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Inicia Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
